# Радар сундуков Fortnite

[Открыть карту v43.10](https://onetapggt-maker.github.io/fortnite-chest-radar/)

Программа для Windows рисует оверлей поверх мини-карты Fortnite. Она распознаёт игровой значок сундука при включённой визуализации звуковых эффектов и сохраняет в локальный список время и примерный район игрока. Точки на карте показывают возможные места появления сундуков.

## Запуск

Установите Python 3.12 для Windows с поддержкой Tkinter. Из папки проекта выполните в PowerShell:

```powershell
py -3.12 -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запустите **Run Radar.cmd**, переключитесь в Fortnite в режиме **«Оконный без рамки»** и включите **«Визуализация звуковых эффектов»**. Управление радаром находится в трее. Если область мини-карты не определяется автоматически, выделите её в разделе **«Настройки → Объекты»**.

В этом же разделе можно отключить **«Подсвечивать светящиеся ящики»**. При появлении звукового значка сундука радар ищет локальное золотое свечение вокруг прямоугольного предмета в кадре и помечает подходящий предмет как возможный сундук.

## Общие наблюдения

Радар автоматически отправляет номер известной точки и версию карты, когда распознаёт игровой значок сундука и достаточно уверенно связывает его с одной ближайшей точкой. Для этого не нужен вход в GitHub. Автоотправку можно выключить в **«Настройки → Объекты → Делиться наблюдениями без аккаунта»**.

Общие отметки за семь дней видны на сайте и обведены фиолетовым на мини-карте. Если радар также распознаёт светящийся ящик в кадре, связанный с такой точкой, рамка ящика тоже становится фиолетовой. Отметка относится к месту возможного появления. Она сохраняется между матчами и не подтверждает, что сундук сейчас закрыт или появился в конкретном матче.

Наблюдения принимает публичный сервис из папки `server`. Он учитывает не более одной отметки на точку в час. GitHub Actions сохраняет агрегированную копию в `community-snapshot.json`. Сайт сначала читает свежие данные, а при недоступности сервиса использует последнюю копию из репозитория.

Ручные отметки примерного района можно по-прежнему публиковать через GitHub Issues с сайта или через **«Замеченные сундуки → Открыть черновик на GitHub»**. Кадры игры и локальный журнал хранятся на компьютере.

Карта острова — [Fortnite-API](https://fortnite-api.com/), точки появления — [Crisis](https://lifecrisis.life/loot). Независимый проект, не связан с Epic Games.
